# Client-Driven Changes
Up: [[00 Start Here]]

From the client demo interviews (including 20 and 24 October, and 11 November — see [[14 Interview Integration Plan (11-11-26)]] for the full breakdown).

## Built or decided
- **Admin + HR merged into one role** (confirmed 11 Nov — corrects the "set aside" line below)
- Editable document types
- File integrity check
- Download and project-edit audit
- Project stakeholders
- Multi-recipient RFI/RFA with no-login reply link
- Outside-geofence clock-in alert (flagged, not blocked)
- PM-only approvals for materials and RFIs (Admin override needs a written reason)
- PM daily, weekly and monthly reports
- Overdue emails: one daily summary per person; Admins get their own items plus a per-project overview
- RFI/RFA can be emailed to the client (outbound only; replies handled in Gmail, status updated manually)
- Roles & Permissions shown as an org-chart hierarchy (Admin and IT Designer at the same level); proposal details in a side panel

## Removed
- Reimbursement claims ("My claims") system-wide
- "My attendance and pay" page

## Decided not to add / set aside
- No separate Project Management **project type** (PM becomes a service on Construction; see [[09 Assumptions Awaiting Confirmation]])
- Set aside: geofence radius cap, DTR photo, screen hiding
- ~~Admin/HR merge~~ — now confirmed built/decided (11 Nov), see above

## New for the December demo
Roles as data, DCO role, confidentiality levels, document access requests ([[09 Plan to December Demo]]).
